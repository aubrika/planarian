# Image generation reference prompts

Built-in image generation was used for the original isolated raster master and
concept board. The reference prompts below use the current lowercase brand
spelling. Version 1.2 rebuilds the wordmarks, identity overview, and organic
animation prototypes directly from the vector master with the bundled scripts.

## Transparent master

Use case: precise-object-edit / logo-brand. Extract and refine ONLY the selected mark C / RETURN from the TOP RIGHT cell of the reference sheet into ONE standalone production logo master. The reference sheet is the edit target; all other marks, text, divider lines, and little thumbnails must be removed. Keep C's design and proportions faithfully: a single stout black planarian flatworm curled into an almost closed circular ring; the broad distinctive spade head sits near the upper right and points diagonally up-right; two round transparent eyespots are staggered diagonally down-right in the head; the pointed tail rises on the right and almost meets the head, leaving the distinctive clean gap near one-to-two o'clock. Keep the large round central negative space, bottom-heavy ring, graceful inner left curve, and head silhouette from C. It must remain the same chosen logo, not a different animal, a power button, or an arrow. Center one large mark with generous equal safe margins on a square truly TRANSPARENT background. Pure solid BLACK filled shapes, with fully transparent eyes, center hole, and head-tail gap. Clean flat vector-like silhouette with smooth contours, no shading, no texture, no gradients, no shadows, no border, no text, no extra symbols. This is the master asset for a coherent icon kit, so silhouette fidelity is the priority.

## Illustrative identity board

Use case: logo-brand / product-mockup. Create ONE beautifully composed identity-kit presentation board for the software project 'planarian', using the exact planarian-loop logo in the reference. Reference is the definitive logo asset: preserve its spade head, diagonal pair of eye holes, near-circular thick tapered ring, open gap beside the head, orientation and proportions. Do not redesign it or substitute a snake/arrow/power button. Repeat that same mark faithfully across applications. Monochrome identity: black, white, warm off-white, quiet graphite grays. No additional brand color or invented slogan. Flat editorial graphic design, restrained contemporary typography, generous space, sharp contrast, practical software identity rather than glossy advertising.

Landscape board, approximately 3:2, legible on a mobile screen. Small heading 'planarian' with subheading 'IDENTITY KIT'. Arrange six well-spaced application panels on a clean off-white ground with hairline grid dividers, alternating some dark and light surfaces, consistent rhythm. Panels:
1. 'PRIMARY MARK': large solid-black symbol on off-white, and a smaller exact white reversed symbol on a charcoal square. Show the master confidently.
2. 'WORDMARK': the symbol paired horizontally with the word 'planarian' in a refined neutral sans serif; below it a stacked symbol-over-name version. Both restrained and readable. Actual wording only 'planarian'.
3. 'APP ICON': two simple rounded-square launcher tiles, charcoal tile with white symbol and white tile with black symbol, with careful equal padding. Small circular avatar version beside them. No gradients, no shine.
4. 'DOCUMENTATION': a cropped clean software documentation header with the black symbol and 'planarian' at the left, small navigation 'Docs' and 'Reference', a big heading 'Getting started', and just two clean schematic content lines. This is an illustrative application of the identity, not a full website design.
5. 'TERMINAL': a minimal dark terminal window, tiny logo and 'planarian' in the window header; inside monospaced text '$ planarian status', then 'All systems healthy'. The symbol is in the graphical header, not ASCII art. No extra commands or invented release numbers.
6. 'BOOT SCREEN': a generous quiet charcoal boot/login splash with a medium white symbol centrally placed and 'planarian' below, one very thin subdued progress line. Calm and trustworthy, not sci-fi or neon.

Make the applications look like one real identity system. The same symbol must appear in every panel. No 3D objects, no human hands, no screens in perspective, no paper texture, no additional logos, no extra decorative elements. This is a polished visual overview accompanying usable vector and raster assets.
